# 03：根评论与回复的拒绝提交和可见错误反馈

> 已发布：[GitHub Issue #5](https://github.com/wxb-gs/live_community/issues/5)。父规格：[#2](https://github.com/wxb-gs/live_community/issues/2)。标签：ready-for-agent。发布日期：2026-10-25。尚未开始实现。

## What to build

用户发表评论或回复时，命中词条的正文不会写成可见评论；输入框下方能够明确显示命中预览，失败保留文字和回复目标。正常评论与回复仍按原流程提交并刷新列表。

## Acceptance criteria

- [ ] 在共用的评论创建应用入口调用真实检测能力，根评论与回复均覆盖，HTTP 与内部 Dubbo 都不能绕过。
- [ ] 检查保持在可见数据写入之前；被拒绝后没有本次新增评论索引、正文或主题计数变化。
- [ ] 保留现有身份、目标可访问性、父评论和回复关系验证，不借过滤错误暴露无权访问的内容。
- [ ] 评论与回复通过复用的结构化错误链路展示命中字段和原文片段，而不是仅产生未处理的 Promise 拒绝。
- [ ] 失败保留输入；回复失败保留回复文字和回复目标。成功后仍能清空输入、结束本次回复并刷新正确的评论列表。
- [ ] 各条评论和回复独立检测，不与父评论、相邻评论或笔记正文拼接。
- [ ] 单次提交最多展示 20 处预览，超出提示还有更多；原文不替换为星号，预览不执行用户输入中的 HTML。
- [ ] 通过评论应用入口及真实事务状态验证根评论、直接回复和子回复的成功与拒绝；正常路径使用真实检测与固定词表，外部系统按已有测试方式隔离。
- [ ] 补评论与回复的错误展示、输入保留和成功恢复的交互验收；不改变现有评论长度限制。
