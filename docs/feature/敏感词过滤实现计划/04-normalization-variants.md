# 04：大小写、全角与英文单字母分隔变形识别

> 已发布：[GitHub Issue #6](https://github.com/wxb-gs/live_community/issues/6)。父规格：[#2](https://github.com/wxb-gs/live_community/issues/2)。标签：ready-for-agent。发布日期：2026-10-25。尚未开始实现。

## What to build

在已有完整发布链路中，让大小写、全角 ASCII 以及明确支持的英文单字母分隔变形得到一致检测；拒绝提示仍准确高亮用户原文。匹配升级由笔记、评论共同的检测能力提供，已接入的场景自动复用。

## Acceptance criteria

- [ ] 对检测副本统一英文大小写和全角 ASCII 宽度，词条 bad 能命中 BAD 与 ｂａｄ；保存和显示的原文保持不变。
- [ ] 不额外进行圈号数字到普通数字等广泛兼容折叠，也不进行繁简、拼音、谐音或近形字符转换。
- [ ] 英文额外识别独立单字母片段；普通空格、制表符、英文连字符、下划线和英文句点属于允许间隔。b-a-d、b a d、b_a_d、b.a.d 及制表符分隔应命中。
- [ ] 正常英文词之间不任意拼接；词条 bad 不因 job advertisement 被去空格而命中。ba d 和 b ad 不按独立单字母变形命中。
- [ ] 英文分隔变形不跨换行，不忽略斜杠、中文标点和零宽字符。其他位置独立存在连续子串时，连续命中仍然有效。
- [ ] 中文保持连续子串规则；词条测试词不通过测-试-词被重构命中。
- [ ] 连续英文子串规则保留：badminton、bad123、_bad_ 仍命中，不能因增加变形规则而恢复完整单词限制。
- [ ] 引用、否定或教学上下文不构成豁免；字段之间、不同提交之间不拼接。
- [ ] 返回的命中区间映射到用户原文，归一化及跨分隔匹配不破坏高亮；用全角字符、制表符、非 BMP 字符及其后的命中验证坐标一致性。
- [ ] 以笔记标题这条已完成链路演示升级后的检测和原文预览，使用参数化样例从应用入口验证正例、反例；当其他入口已接入时运行其现有回归。
- [ ] 不限定 AC 自动机、Trie、正则或第三方库，不以内部节点、扫描次数或未验证的性能数字作为完成标准。
