# 02：笔记正文与标题独立检查、分字段提示

> 已发布：[GitHub Issue #4](https://github.com/wxb-gs/live_community/issues/4)。父规格：[#2](https://github.com/wxb-gs/live_community/issues/2)。标签：ready-for-agent。发布日期：2026-10-25。尚未开始实现。

## What to build

作者发布笔记时，服务端已保存的标题和正文都受到检查。正文命中会在正文输入框下方显示错误预览；两个字段不会拼接出原本不存在的词。作者可以修改保留的输入后再次提交。

## Acceptance criteria

- [ ] 复用 01 的应用层检测、错误契约和前端预览，增加服务端草稿正文的权威检查。
- [ ] 标题与正文分别检查；标题末尾为测试、正文开头为词时，不得合成为测试词命中。正文单独包含测试词时必须拒绝。
- [ ] 任一字段命中均不能公开笔记；失败保留原有草稿及页面标题、正文和封面状态。
- [ ] 命中详情正确标识所属字段，页面在对应字段下方展示预览；不将归一化或其他字段中的坐标用于当前原文高亮。
- [ ] 单次发布的预览上限为两个字段合计最多 20 处，而非每个字段各 20 处；超出提示还有更多，仍拒绝提交。
- [ ] 真正发布的文本必须就是检查通过的服务端文本，不能用前端另传的安全副本替代实际草稿；实现不能引入检查旧版本而发布新版本的窗口。
- [ ] 在发布应用入口通过真实检测验证仅标题命中、仅正文命中、两个字段命中、两个字段均通过，以及跨字段不能拼接的情况。
- [ ] 验证拒绝前后公开状态与新增发布事件；保持已有作者权限和上传确认行为。
- [ ] 补正文错误预览、字段区分及失败输入保留的界面验收；不借此增加草稿更新接口或重做重试复用机制。
